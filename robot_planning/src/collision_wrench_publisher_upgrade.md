# Collision Wrench Publisher Upgrade Plan

This document describes how to upgrade `online_collision_debugger.cpp` so it can publish collision-avoidance wrench data for the main controller while keeping the current RViz collision markers as debug tools.

## Goal

Use the existing contact distance and normal/vector data from Tesseract collision checking to compute a real-time repulsive collision wrench:

\[
F_{collision}
=
\begin{bmatrix}
F_x & F_y & F_z & \tau_x & \tau_y & \tau_z
\end{bmatrix}^T
\]

and publish it as a ROS topic that the main controller can subscribe to.

For now:

- publish the total wrench as `geometry_msgs/msg/WrenchStamped`
- keep the current debug text topic
- keep the current RViz markers only when `debug_markers_enabled=true`
- add a force-arrow marker after each force calculation
- make force-arrow length proportional to force magnitude

## Force Equation

For each contact pair:

- `d_i` = contact distance
- `n_i` = push-away direction
- `d0` = collision influence distance
- `d_safe` = hard safety distance

Use:

\[
F_{rep,i}
=
k_{rep}
\left(
\frac{1}{d_i}
-
\frac{1}{d_0}
\right)
\frac{1}{d_i^2}
n_i
\]

only when:

\[
d_i < d_0
\]

Then add a stronger hold force when the robot is too close:

\[
F_{hold,i}
=
k_{hold}(d_{safe}-d_i)n_i
\]

only when:

\[
d_i < d_{safe}
\]

Total per-contact force:

\[
F_i = F_{rep,i} + F_{hold,i}
\]

Clamp:

\[
F_i \leftarrow sat(F_i, F_{max,contact})
\]

Total force:

\[
F_{total} = \sum_i F_i
\]

Clamp again:

\[
F_{total} \leftarrow sat(F_{total}, F_{max,total})
\]

---

## Torque Equation

Let:

\[
r_i = p_i - p_{ref}
\]

where:

- \(p_i\) = contact point
- \(p_{ref}\) = wrench reference point, usually the current EE/tool position

Then:

\[
\tau_i = r_i \times F_i
\]

Total torque:

\[
\tau_{total} = \sum_i \tau_i
\]

For first testing, the main controller can use only the force part and ignore torque.

## Helper: Clamp Vector Norm

Add:

```cpp
static Eigen::Vector3d clampNorm(const Eigen::Vector3d &v, double max_norm)
{
    if (!v.allFinite())
        return Eigen::Vector3d::Zero();

    const double n = v.norm();
    if (max_norm <= 0.0 || n <= max_norm || n < 1e-9)
        return v;

    return v * (max_norm / n);
}
```

## Helper: Contact Force

Add:

```cpp
Eigen::Vector3d computeCollisionForce(
    double distance,
    const Eigen::Vector3d &push_dir) const
{
    const double d0 = std::max(1e-6, collision_influence_distance_);
    const double d_safe = std::max(0.0, collision_safe_distance_);

    if (distance >= d0)
        return Eigen::Vector3d::Zero();

    Eigen::Vector3d n = push_dir;
    if (!n.allFinite() || n.norm() < 1e-9)
        return Eigen::Vector3d::Zero();
    n.normalize();

    const double d = std::max(distance, 1e-4);

    double rep_mag =
        collision_k_rep_ *
        (1.0 / d - 1.0 / d0) /
        (d * d);

    double hold_mag = 0.0;
    if (distance < d_safe)
        hold_mag = collision_k_hold_ * (d_safe - distance);

    Eigen::Vector3d f = (rep_mag + hold_mag) * n;

    return clampNorm(f, collision_force_max_per_contact_);
}
```

## Helper: Publish Total Wrench

Add:

```cpp
void publishCollisionWrench(
    const Eigen::Vector3d &force,
    const Eigen::Vector3d &torque)
{
    if (!publish_collision_wrench_)
        return;

    geometry_msgs::msg::WrenchStamped msg;
    msg.header.stamp = this->now();
    msg.header.frame_id = wrench_frame_;

    msg.wrench.force.x = force.x();
    msg.wrench.force.y = force.y();
    msg.wrench.force.z = force.z();

    msg.wrench.torque.x = torque.x();
    msg.wrench.torque.y = torque.y();
    msg.wrench.torque.z = torque.z();

    collision_wrench_pub_->publish(msg);
}
```

## Force Arrow Marker

Update `addForceArrow()` so the arrow length is proportional to force magnitude:

```cpp
void addForceArrow(visualization_msgs::msg::MarkerArray &marker_array,
                   const Eigen::Vector3d &start,
                   const Eigen::Vector3d &force,
                   const std::string &ns,
                   int &id_counter)
{
    if (!debug_markers_enabled_)
        return;

    if (!force.allFinite() || force.norm() < 1e-9)
        return;

    const double force_ratio =
        std::clamp(force.norm() / std::max(1e-9, collision_force_max_per_contact_),
                   0.0, 1.0);

    const double arrow_length =
        force_arrow_min_length_
        + force_ratio * (force_arrow_max_length_ - force_arrow_min_length_);

    const Eigen::Vector3d direction = force.normalized();
    const Eigen::Vector3d end = start + direction * arrow_length;

    visualization_msgs::msg::Marker arrow_marker;
    arrow_marker.header.frame_id = marker_frame_;
    arrow_marker.header.stamp = this->now();
    arrow_marker.ns = ns;
    arrow_marker.id = id_counter++;
    arrow_marker.type = visualization_msgs::msg::Marker::ARROW;
    arrow_marker.action = visualization_msgs::msg::Marker::ADD;

    arrow_marker.points.push_back(toPoint(start));
    arrow_marker.points.push_back(toPoint(end));

    arrow_marker.scale.x = 0.01;
    arrow_marker.scale.y = 0.025;
    arrow_marker.scale.z = 0.04;

    arrow_marker.color.r = 0.0;
    arrow_marker.color.g = 0.85;
    arrow_marker.color.b = 1.0;
    arrow_marker.color.a = 0.9;

    marker_array.markers.push_back(arrow_marker);
}
```

This means:

- small collision force → short arrow
- large collision force → long arrow
- capped at `force_arrow_max_length`

## Main Callback Change

Inside `jointStateCallback()`, before looping contacts:

```cpp
Eigen::Vector3d total_force = Eigen::Vector3d::Zero();
Eigen::Vector3d total_torque = Eigen::Vector3d::Zero();
```

Compute reference point:

```cpp
Eigen::Vector3d wrench_ref = Eigen::Vector3d::Zero();

auto it_ref = current_state.link_transforms.find(wrench_reference_link_);
if (it_ref != current_state.link_transforms.end())
{
    wrench_ref = it_ref->second.translation();
}
```

Inside each valid contact result:

```cpp
const Eigen::Vector3d normal_0_to_1 = contactNormal0To1(result);

// Tesseract normal convention:
// normal_0_to_1 pushes link1 away from link0.
// So the force on link0 is -normal.
// The force on link1 is +normal.
const Eigen::Vector3d force_on_link0 =
    computeCollisionForce(result.distance, -normal_0_to_1);

const Eigen::Vector3d force_on_link1 =
    computeCollisionForce(result.distance, normal_0_to_1);

// Choose the force to publish for robot avoidance.
// If both links are robot links, summing both cancels.
// For external obstacle avoidance, publish the force on the robot-side link only.
//
// Safe default for now:
// accumulate both as debug markers, but accumulate the stronger one into total.
Eigen::Vector3d force_for_controller = force_on_link0;
if (force_on_link1.norm() > force_on_link0.norm())
    force_for_controller = force_on_link1;

const Eigen::Vector3d contact_point =
    0.5 * (result.nearest_points[0] + result.nearest_points[1]);

total_force += force_for_controller;

const Eigen::Vector3d r = contact_point - wrench_ref;
total_torque += r.cross(force_for_controller);
```

Then add markers after calculating force:

```cpp
if (debug_markers_enabled_)
{
    addDistanceLine(marker_array, result, id_counter);
    addContactPoint(marker_array, result, 0, id_counter);
    addContactPoint(marker_array, result, 1, id_counter);
    addVectorToObstacleArrow(marker_array, result, normal_0_to_1, id_counter);

    addForceArrow(marker_array,
                  result.nearest_points[0],
                  force_on_link0,
                  "collision_push_force_link0",
                  id_counter);

    addForceArrow(marker_array,
                  result.nearest_points[1],
                  force_on_link1,
                  "collision_push_force_link1",
                  id_counter);

    addForceArrow(marker_array,
                  contact_point,
                  force_for_controller,
                  "collision_force_for_controller",
                  id_counter);
}
```

After the contact loop:

```cpp
total_force = clampNorm(total_force, collision_force_max_total_);

publishCollisionWrench(total_force, total_torque);
```

Only publish markers if debug enabled:

```cpp
if (debug_markers_enabled_)
{
    marker_pub_->publish(marker_array);
}
```

## Important Warning About Force Direction

Do not blindly sum `force_on_link0 + force_on_link1`.

For the same contact pair:

\[
F_{link0} = -F_{link1}
\]

So summing both can cancel to zero.

For the main controller, you need the force on the robot side only.

If both links are robot links, this is self-collision. In that case:

- use it for warning/debug
- do not send equal opposite forces as one EE wrench
- later, handle link-level avoidance with multiple control points or QP

For now, the safe simple controller signal is:

```cpp
force_for_controller = stronger of force_on_link0 / force_on_link1
```

or choose based on which link is closer to your controlled body.

Callback:

```cpp
void collisionWrenchCallback(
    const geometry_msgs::msg::WrenchStamped::SharedPtr msg)
{
    latest_collision_wrench_ <<
        msg->wrench.force.x,
        msg->wrench.force.y,
        msg->wrench.force.z,
        msg->wrench.torque.x,
        msg->wrench.torque.y,
        msg->wrench.torque.z;

}
```

Inside impedance controller:

```cpp
Eigen::Matrix<double, 6, 1> F_collision;
F_collision.setZero();

if ((this->now() - t_last_collision_wrench_cb_).seconds() < 0.2)
{
    F_collision = latest_collision_wrench_;
}
```

Then:

```cpp
xddot_ref =
    M_inv *
    (
        K_adapt * e
      + D_error * edot
      + F_collision
      - D_adapt * xdot_ref_
    );
```

## Notes

This upgrade keeps the collision node independent:

- collision node computes contact distance and force
- main controller consumes only `F_collision`
- controller pub/sub and trajectory logic stay unchanged

This is the correct architecture for real-time local collision avoidance.
